# HRMS QA Assignment

This repository contains the work done for the QA Engineer Fellowship at DeepThought. It includes:

- Manual and automated test cases
- Bug reports
- A hand-drawn mind map
- Self-evaluation

## Key Features

- Understanding of the HRMS workflow
- Test case design for edge cases
- Bug tracking and reporting
- QA safety net implementation

## How to Use

- Review the manual test cases for user-centric testing
- Run the automated test cases using Python + Selenium
- View the bug reports for detailed issue tracking
- Use the mind map to visualize the system
- Read the self-evaluation for insights into the QA process
